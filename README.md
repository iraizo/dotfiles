dotfiles for my main desktop (Arch Linux).

Includes:\
fish - shell\
niri - window manager\
wezterm - terminal emulator

zed - editor\
helix - editor

nix - nix config\
starship - shell prompt\
direnv - per-directory env loading\
yazi - terminal file manager\
eza - file listing theme / ls alternative\
bat - pager theme / cat alternative
btop - process monitor

Install via:

```sh
sh -c "$(curl -fsLS get.chezmoi.io)" -- init --apply iraizo
```
